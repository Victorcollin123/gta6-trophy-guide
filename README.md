Offline GTA VI trophy guide and tracker for PS5: all 55 official trophies with guides in our own words, each citing its sources, a localStorage checklist with export and import, search and filters, a spoiler setting, a roadmap to the platinum and a missables page.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network calls, no outside images.
