Offline GTA VI trophy guide and tracker for PS5 — all 55 official trophies with a guide to each, a roadmap to the platinum, the one possibly missable trophy flagged, and a checklist that saves your progress in the browser. Built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off.
